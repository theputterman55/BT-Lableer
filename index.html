Shortcuts

B / V / HDraw, Select (move boxes), Pan
DragDraw a box. Click a box to select it. Drag its handles to resize.
Select toolDrag inside a box to move it
1–9Pick a class. If a box is selected, it changes that box's class.
A / DPrevious / next image (arrow keys too when no box is selected)
ArrowsNudge the selected box 1 px (hold Shift for 10 px)
CCopy boxes from the previous image (great for bags sitting on boards)
EMark image as empty background, then go to next
UJump to next unlabeled image
DeleteDelete the selected box
Ctrl+Z / Ctrl+YUndo / redo
Wheel, + / −, 0Zoom, zoom, fit to window
Space + dragPan (also right-drag, or two fingers on a touch screen)
PinchZoom on a touch screen
RSelected bag has stopped: resting (red). Press again to clear
MA resting bag got bumped: moved (green)
XSelected bag went in the hole
N / Shift+NNext / previous bag to draw (Player 1 bag 1, Player 2 bag 1, ...)
PSwitch between Player 1 and Player 2
TGive the selected box the bag chosen under "Now drawing"
ZHold view: keep zoom and position on the next image
LShow or hide box labels
EscDeselect
